# 1. Introduction

This document defines the official opcode allocation for ISA Version 1.

Each instruction is uniquely identified by a 5-bit opcode.

The opcode determines:

- Instruction category
- Instruction format
- Execution behavior
- Decoder operation

---

# 2. Opcode Space

The processor uses a 5-bit opcode field.

| Property | Value |
|----------|-------|
| Opcode Width | 5 bits |
| Total Opcode Space | 32 instructions |
| Implemented Instructions | 18 |
| Reserved Opcodes | 14 |

# 4. Reserved Opcode Space

The remaining opcode values are reserved for future ISA revisions.

| Binary Range | Decimal Range | Status |
|--------------|---------------|--------|
| 10010 – 11111 | 18 – 31 | Reserved |

Reserved opcodes shall not be generated by software targeting ISA Version 1.

Execution of a reserved opcode is currently **undefined**.

Future revisions may assign new meanings while maintaining backward compatibility where possible.

# 7. Decoder Requirements

The instruction decoder shall:

1. Extract the 5-bit opcode field.
2. Determine the instruction format.
3. Decode operands.
4. Generate execution control signals.
5. Detect reserved opcodes.

Reserved opcode handling is implementation-defined in ISA Version 1.

---

# 8. Future Opcode Allocation

The remaining opcode space is intended for future ISA extensions.

Possible additions include:

| Instruction | Purpose |
|-------------|---------|
| SHL | Logical Shift Left |
| SHR | Logical Shift Right |
| ROL | Rotate Left |
| ROR | Rotate Right |
| CALL | Subroutine Call |
| RET | Return from Subroutine |
| PUSH | Push to Stack |
| POP | Pop from Stack |
| MUL | Multiplication |
| DIV | Division |
| MOD | Modulo |
| INT | Software Interrupt |

These instructions are **not part of ISA Version 1**.

---

# 9. Design Notes

The opcode allocation follows these principles:

- Similar instructions are grouped together.
- Arithmetic instructions occupy the lowest opcode range.
- Logical instructions follow arithmetic instructions.
- Memory instructions are grouped together.
- Control-flow instructions occupy a contiguous block.
- System instructions are placed after control instructions.
- Reserved opcode space is preserved for future ISA evolution.
