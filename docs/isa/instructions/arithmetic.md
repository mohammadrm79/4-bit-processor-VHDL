# Arithmetic Instructions

| Instruction | Opcode | Operation |
|---|---|---|
| ADD | 00000 | `Rd ← Rs1 + Rs2` |
| SUB | 00001 | `Rd ← Rs1 - Rs2` |
| INC | 00010 | `Rd ← Rs1 + 1` |
| DEC | 00011 | `Rd ← Rs1 - 1` |

All four operations enable the ALU-result register and flag register in `EXECUTE`, then write `Rd` from the registered result in `WRITE_BACK`.

Arithmetic is modulo 16 at the destination. Z, C, and N are generated by the ALU. V is computed for signed ADD and SUB, and is also set for INC of `0111` and DEC of `1000`.

## Not Implemented

`CMP` is not implemented. There is no arithmetic instruction that updates flags without writing a destination register.
