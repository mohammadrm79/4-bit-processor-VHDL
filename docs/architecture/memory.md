# Memory Architecture

## Instruction memory

`instruction_memory` is a 256 × 16-bit model by default. It initializes from a hexadecimal text file using `hread`; its default `PROGRAM_FILE` is `tb/programs/program_add.mem`. Reads are combinational. Addresses outside `DEPTH`, or addresses containing unknown values, return an all-zero instruction.

## Data memory

`data_memory` is a 256 × 4-bit model by default. It is reset to zero synchronously, reads combinationally, and writes on a rising edge when `write_enable='1'`. Out-of-range reads return zero.

## Integrated address and access behavior

Although I-type instructions contain `immediate[7:0]`, `cpu_core` does not use it for data-memory addressing. It zero-extends register-file source B to 11 bits. Data-memory read is always electrically available; `memory_read_enable` is generated by the FSM but is not connected to `data_memory`.

## Not Implemented

Direct immediate addressing, an external memory bus, memory wait states, memory protection, and a synthesis-safe instruction-ROM implementation are not implemented.
