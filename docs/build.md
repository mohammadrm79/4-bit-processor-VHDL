# Build Artifacts

## Overview

All generated files are placed under the `build/` directory.

The `build/` directory is created automatically and contains logs, simulation outputs, synthesized netlists, and other generated artifacts. Nothing inside this directory is intended to be edited manually.

---

# Directory Structure

```text
build/
├── logs/
├── synth/
├── waves/
└── work/
```

---

# logs/

Contains log files generated by the project scripts.

Typical files:

```text
lint_20260728_214851.log
sim_20260728_214902.log
synth_20260728_215010.log
```

These logs are useful for debugging build, simulation, and synthesis problems.

Generated by:

- lint.sh
- sim.sh
- synth.sh
- test.sh

---

# synth/

Contains synthesis outputs generated from the VHDL design.

Typical contents:

```text
system_top.v
system_top.dot
system_top.raw.vhdl
system_top.netlist.vhdl
system_top_opt.v
system_top.json
system_top.blif
system_top.edif
system_top.rtlil
```

Depending on the synthesis configuration, additional formats may also be generated.

Purpose of common files:

| File | Description |
|------|-------------|
| system_top.v | Verilog netlist generated by GHDL |
| system_top.raw.vhdl | Raw synthesized VHDL |
| system_top.netlist.vhdl | Optimized VHDL netlist |
| system_top.dot | Graphviz representation of the design |
| system_top.json | JSON netlist for external tools |
| system_top.blif | Berkeley Logic Interchange Format |
| system_top.edif | EDIF netlist |
| system_top.rtlil | RTLIL intermediate representation |
| system_top_opt.v | Optimized Verilog produced by Yosys |

These files are mainly intended for synthesis, visualization, and FPGA/ASIC design flows.

Generated by:

```bash
make synth
```

or

```bash
./scripts/synth.sh
```

---

# waves/

Contains waveform files generated during simulation.

Typical files:

```text
cpu.ghw
```

or

```text
cpu.vcd
```

These files can be viewed using waveform viewers such as GTKWave.

Generated by:

```bash
make sim
```

---

# work/

Contains temporary compilation artifacts generated by GHDL.

Examples include:

```text
work-obj08.cf
```

These files store compiled VHDL libraries and are recreated automatically whenever needed.

Users normally do not need to modify this directory.

---

# Automatic Cleanup

Generated files can be removed with:

```bash
make clean
```

or

```bash
./scripts/clean.sh
```

The cleanup script removes generated build artifacts while preserving the project source files.

---

# Notes

- The `build/` directory is entirely generated.
- No source files are stored in this directory.
- Files are recreated automatically whenever the corresponding scripts are executed.
- Log files are timestamped to preserve previous execution history.
