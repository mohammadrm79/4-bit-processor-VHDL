# اسکریپت‌های پروژه

## معرفی

پروژه **RISC-4 Educational CPU** مجموعه‌ای از اسکریپت‌های Bash و یک فایل **Makefile** را برای خودکارسازی مراحل توسعه در اختیار قرار می‌دهد.

این اسکریپت‌ها وظایفی مانند تحلیل کد، اسمبل برنامه‌ها، شبیه‌سازی، اجرای تست‌ها، سنتز و پاک‌سازی فایل‌های تولیدشده را انجام می‌دهند.

تمام اسکریپت‌ها در مسیر زیر قرار دارند:

```text
scripts/
├── assembler.awk
├── assembler.sh
├── clean.sh
├── lint.sh
├── sim.sh
├── synth.sh
└── test.sh
```

---

# Makefile

برای ساده‌تر شدن اجرای مراحل مختلف پروژه، یک فایل **Makefile** در ریشه پروژه قرار دارد.

## اهداف (Targets)

| دستور | توضیح |
|-------|-------|
| `make` | اجرای هدف پیش‌فرض (`all`) |
| `make all` | اجرای گردش‌کار پیش‌فرض پروژه |
| `make lint` | بررسی فایل‌های VHDL |
| `make asm` | اسمبل تمام برنامه‌های اسمبلی |
| `make sim` | اجرای شبیه‌سازی |
| `make test` | اجرای تمام تست‌ها |
| `make synth` | اجرای فرآیند سنتز |
| `make clean` | حذف فایل‌های تولیدشده |

### مثال

```bash
make
```

```bash
make test
```

```bash
make synth
```

# assembler.awk

## وظیفه

پیاده‌سازی اسمبلر پردازنده RISC-4.

این برنامه فایل‌های اسمبلی را به کد ماشین تبدیل می‌کند تا توسط حافظه دستورالعمل قابل استفاده باشند.

### قابلیت‌ها

- پشتیبانی از Label
- دستورات Immediate
- دستورات سه‌ثباتی (Three Register)
- دستورات حافظه
- دستورات پرش
- توضیحات (Comment)

### دستورات پرش

- JMP
- JZ
- JC

# assembler.sh

## وظیفه

تمام فایل‌های اسمبلی موجود در مسیر زیر را اسمبل می‌کند:

```text
tb/programs/asm/
```

و فایل‌های خروجی را در مسیر زیر تولید می‌کند:

```text
tb/programs/bin/
```

## نحوه اجرا

```bash
./scripts/assembler.sh
```

## فایل‌های تولیدشده

```text
tb/programs/bin/*.mem
```

# lint.sh

## وظیفه

تمام فایل‌های VHDL پروژه را با استفاده از **GHDL** تحلیل می‌کند.

این اسکریپت موارد زیر را بررسی می‌کند:

- خطاهای نحوی
- وابستگی فایل‌ها
- صحت Packageها
- خطاهای تحلیل VHDL

## نحوه اجرا

```bash
./scripts/lint.sh
```

## خروجی

```text
build/logs/lint_*.log
```

# sim.sh

# synth.sh

## وظیفه

فرآیند سنتز پروژه را با استفاده از **GHDL** و **Yosys** انجام می‌دهد.

این اسکریپت مراحل زیر را اجرا می‌کند:

1. تحلیل فایل‌های VHDL
2. بررسی قابلیت سنتز
3. تولید Netlist
4. تولید فایل Verilog
5. بهینه‌سازی توسط Yosys
6. تولید فایل‌های خروجی سنتز

## نحوه اجرا

```bash
./scripts/synth.sh
```

## فایل‌های تولیدشده

تمام خروجی‌ها در مسیر زیر ذخیره می‌شوند:

```text
build/synth/
```

از جمله:

```text
system_top.vhdl
system_top_raw.vhdl
system_top.v
system_top.dot

system_top_opt.v
system_top.json
system_top.rtlil
system_top.blif
system_top.edif
```

# clean.sh

## وظیفه

تمام فایل‌های تولیدشده توسط پروژه را حذف می‌کند.

این اسکریپت هیچ‌یک از فایل‌های منبع یا مستندات پروژه را تغییر نمی‌دهد.

## نحوه اجرا

```bash
./scripts/clean.sh
```

## فایل‌های حذف‌شده

تمام فایل‌های موجود در مسیر زیر:

```text
build/
```

از جمله:

- فایل‌های لاگ
- فایل‌های شبیه‌سازی
- خروجی تست‌ها
- فایل‌های سنتز
- فایل‌های موقت

# گردش‌کار پیشنهادی

چرخه معمول توسعه پروژه به صورت زیر است:

```text
ویرایش کد VHDL
        │
        ▼
make lint
        │
        ▼
make test
        │
        ▼
رفع خطاها
        │
        ▼
make synth
```

# خلاصه ساختار پروژه

| پوشه | توضیح |
|------|-------|
| `scripts/` | اسکریپت‌های خودکارسازی |
| `src/` | کدهای RTL |
| `tb/` | تست‌بنچ و برنامه‌های اسمبلی |
| `build/` | فایل‌های تولیدشده |
| `docs/` | مستندات پروژه |

# نکات

- تمام اسکریپت‌ها با **Bash** نوشته شده‌اند.
- اسمبلر پروژه با **GNU AWK** پیاده‌سازی شده است.
- فایل‌های تولیدشده تا حد امکان در پوشه `build/` ذخیره می‌شوند.
- فرآیند سنتز بر پایه **GHDL** و **Yosys** انجام می‌شود.
- استفاده از **Makefile** ساده‌ترین روش برای اجرای مراحل مختلف پروژه است.
