# نیازمندی‌های پروژه

## معرفی

این پروژه یک پردازنده آموزشی ۴ بیتی مبتنی بر زبان VHDL است و برای تحلیل، شبیه‌سازی، اسمبل برنامه‌ها و سنتز سخت‌افزار از مجموعه‌ای از ابزارهای متن‌باز استفاده می‌کند.

تمام ابزارهای موردنیاز در سیستم باید قبل از اجرای اسکریپت‌های پروژه نصب شده باشند.

---

## ابزارهای موردنیاز

### GHDL

برای:

- تحلیل کدهای VHDL
- بررسی خطاهای نحوی (Lint)
- شبیه‌سازی
- تولید نت‌لیست برای سنتز

نسخه پیشنهادی:

```
GHDL >= 5.0
```

---

### Yosys

برای:

- خواندن نت‌لیست Verilog تولیدشده توسط GHDL
- انجام بهینه‌سازی منطقی
- تولید خروجی‌های سنتز

نسخه پیشنهادی:

```
Yosys >= 0.52
```

---

### Graphviz

برای تولید نمودار ساختار سخت‌افزار.

نسخه پیشنهادی:

```
Graphviz >= 2.40
```

---

### GNU AWK

برای اجرای اسمبلر پروژه.

نسخه پیشنهادی:

```
gawk >= 5.0
```

---

### GNU Make

برای اجرای اهداف (Targets) پروژه.

نسخه پیشنهادی:

```
GNU Make >= 4.0
```

---

## ابزارهای اختیاری

### GTKWave

برای مشاهده فایل‌های Waveform تولیدشده توسط شبیه‌سازی.

---

## سیستم‌عامل‌های پشتیبانی‌شده

پروژه روی سیستم‌عامل‌های زیر آزمایش شده است:

- Linux
- Windows (WSL)
- macOS (به‌صورت نظری)

---

## ساختار اجرای پروژه

اسکریپت‌های پروژه در پوشه زیر قرار دارند:

```
scripts/
```

مهم‌ترین اسکریپت‌ها:

- lint.sh
- assembler.sh
- sim.sh
- synth.sh
- test.sh
- clean.sh

---

## خروجی‌های تولیدشده

تمام فایل‌های تولیدشده هنگام اجرای پروژه در پوشه زیر ذخیره می‌شوند:

```
build/
```

این پوشه شامل موارد زیر است:

- فایل‌های لاگ
- نت‌لیست‌های سنتز
- فایل‌های شبیه‌سازی
- خروجی تست‌ها
- فایل‌های میانی پروژه

---

## نصب سریع (Ubuntu)

```bash
sudo apt update

sudo apt install \
    ghdl \
    yosys \
    graphviz \
    gawk \
    make
```

---

## بررسی نصب ابزارها

```bash
ghdl --version
yosys -V
dot -V
gawk --version
make --version
```

در صورت نمایش نسخه هر ابزار، نصب آن با موفقیت انجام شده است.
