# معماری پردازنده

مستندات معماری، پیاده‌سازی یکپارچه `system_top` → `cpu_core` را توصیف می‌کنند.

| سند | موضوع |
|---|---|
| `cpu_overview.md` | entityها و اتصال‌های سطح بالا |
| `datapath.md` | مسیرهای Register، ALU، Write Back و operand |
| `control_unit.md` | حالت‌ها و خروجی‌های `control_fsm` |
| `memory.md` | مدل‌های memory و آدرس‌دهی واقعی |
| `timing.md` | timing حالت clocked و به‌روزرسانی داده |

فایل‌های `docs/diagrams/` placeholder خالی هستند؛ هیچ diagramی اکنون پیاده‌سازی نشده است.
