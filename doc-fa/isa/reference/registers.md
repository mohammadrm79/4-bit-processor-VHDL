# مشخصات Register File

Register file دارای هشت Register چهار بیتی هم‌ارز معماری است.

| Encoding | Register |
|---|---|
| 000 | R0 |
| 001 | R1 |
| 010 | R2 |
| 011 | R3 |
| 100 | R4 |
| 101 | R5 |
| 110 | R6 |
| 111 | R7 |

readها از دو port مستقل ترکیبی هستند. writeها همزمان و در `write_enable='1'` رخ می‌دهند. Reset همه Registerها را همزمان صفر می‌کند. R0 قابل نوشتن است و Register صفر ثابت نیست.

فقط R0–R3 توسط top-level CPU به‌صورت debug خروجی می‌شوند؛ این موضوع دسترسی R4–R7 را تغییر نمی‌دهد.
