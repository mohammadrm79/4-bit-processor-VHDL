# Format Instruction R-Type

Opcodeهای R-type عبارت‌اند از `ADD`، `SUB`، `INC`، `DEC`، `AND`، `OR`، `XOR`، `NOT`، `SHL` و `SHR`.

```text
15        11 10      8 7       5 4       2 1     0
+------------+---------+---------+---------+-------+
|   opcode   |   Rd    |   Rs1   |   Rs2   | low2  |
+------------+---------+---------+---------+-------+
```

operationهای دودویی از `Rs1` و `Rs2` استفاده کرده و در `Rd` می‌نویسند. `INC`، `DEC` و `NOT` از `Rs1` استفاده می‌کنند؛ میدان `Rs2` decode می‌شود اما بر result ALU اثر ندارد. `SHL` و `SHR`، `Rs1` را یک bit shift می‌دهند.

بیت‌های `[1:0]` توسط Decoder یا core مصرف نمی‌شوند. RTL صفر بودن آن‌ها را الزامی نمی‌کند.

## پیاده‌سازی نشده

syntax دو-عملوندی مخرب (`Rd ← Rd op Rs`) و `CMP` پیاده‌سازی نشده‌اند.
