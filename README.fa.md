# پردازنده آموزشی RISC-4

این مخزن پیاده‌سازی فعلی VHDL یک پردازندهٔ آموزشی ۴ بیتی را نگه‌داری می‌کند. منبع حقیقت، فایل‌های VHDL هستند؛ مستندات برای توصیف همان پیاده‌سازی به‌روز شده‌اند.

ویژگی‌های پیاده‌سازی‌شده شامل دستورهای ۱۶ بیتی، ۸ ثبات همه‌منظورهٔ ۴ بیتی، کدعمل ۵ بیتی، حافظهٔ دستور و دادهٔ جدا، و بازنشانی همزمانِ فعال-بالا است.

برای مشخصات دقیق ISA و محدودیت‌های فعلی به [docs/isa/README.md](docs/isa/README.md) و برای وضعیت شبیه‌سازی و آزمون به [docs/reports/README.md](docs/reports/README.md) مراجعه کنید.
