# معرفی

**پردازنده آموزشی RISC-4** یک پردازنده متن‌باز است که به‌طور کامل با **VHDL-2008** پیاده‌سازی شده است. هدف این پروژه نمایش کامل مراحل طراحی یک پردازنده RISC، از تعریف مجموعه دستورالعمل‌ها (ISA) و طراحی RTL گرفته تا شبیه‌سازی، سنتز، آزمون و مستندسازی است.

این پردازنده با وجود سادگی، دارای معماری ماژولار و ساختاریافته است و برای موارد زیر مناسب است:

- آموزش طراحی مدارهای دیجیتال
- درس معماری کامپیوتر
- آموزش FPGA
- یادگیری زبان VHDL
- آزمایشگاه‌های طراحی پردازنده
- یادگیری شخصی
- پروژه‌های تحقیقاتی و آموزشی

این مخزن شامل تمام فایل‌های موردنیاز برای درک، شبیه‌سازی، آزمون و سنتز پردازنده بوده و تنها به ابزارهای متن‌باز رایج نیاز دارد.

---

# اهداف پروژه

هدف این پروژه ارائه یک پردازنده کوچک اما کامل برای آموزش مفاهیم زیر است:

- معماری مجموعه دستورالعمل‌ها (ISA)
- طراحی ماژولار RTL
- مسیر داده (Datapath) سه‌ثباتی
- واحد کنترل مبتنی بر ماشین حالت متناهی (FSM)
- فایل ثبات‌ها (Register File)
- واحد حساب و منطق (ALU)
- رمزگشایی دستورالعمل‌ها
- شمارنده برنامه (Program Counter)
- رابط حافظه
- آزمون خودکار
- سنتز سخت‌افزاری
- مستندسازی کامل

در این پروژه خوانایی، سادگی و ارزش آموزشی نسبت به بیشینه‌سازی کارایی در اولویت قرار گرفته است.

# دستورات ساخت

دستورات متداول:

```bash
make lint
```

تحلیل و بررسی تمام فایل‌های VHDL.

```bash
make test
```

اجرای اسمبلر، شبیه‌سازی و تمام تست‌های خودکار.

```bash
make sim
```

اجرای شبیه‌سازی پردازنده.

```bash
make synth
```

تولید فایل‌های سنتز.

```bash
make clean
```

حذف فایل‌های تولیدشده.
